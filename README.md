タイトル：借金返さないと終わるぜ！！



借金返さないと終わるぜ！！は、コインを使ってお金を獲得し、借金の返済を目指すプッシャーゲームです。



プレイヤーはコインを発射してプッシャー台に投入し、コインを落としてお金を獲得します。制限時間やターン数が設定されており、限られた時間の中で借金を返済するゲーム性にしています。

操作	キー

左右移動	A / D

コイン発射	マウス左クリック

返済額入力	数字キー入力(A / Dで1枚単位の調整可能)

返済確定	Enter

タイトルへ戻る	右下のUIを左クリック

ゲームシステム

コイン発射



プレイヤーを左右に移動させ、コインを発射します。



複数種類のコインPrefabからランダムに選択して生成し、Rigidbodyの力を利用してプッシャー台へ投入します。



コイン獲得

落下したコインを検知すると、所持コインと所持金を増加させます。



ボーナスコイン

特定のエリアにコインが入ると、追加のコインをランダムな位置に生成します。



借金返済

獲得したお金を使って借金を返済します。



所持金と借金の金額を超えないように返済額を制限し、返済後に次のターンへ進みます。



ラウンド・ターン

最大3ラウンド、1ラウンドにつき3ターンでゲームを進行します。



制限時間が終了すると返済画面へ移行し、残りターン数が少なくなるとUIを点滅させて警告します。



工夫した点

コインのランダム生成



複数種類のコインPrefabを登録し、発射時やボーナス発生時にランダムでコインの種類を選択するよう実装しました。



コインをPrefabとして分けることで、種類を追加する際にも発射処理を変更せずに対応できるようにしました。



ゲーム状態の一元管理

GameManagerを作成し、所持金・借金・ラウンド・ターン数などのゲーム進行に必要な情報を一元管理しました。

シーンを切り替えてもゲームの状態を保持できるようにしています。



Input System

Unity Input Systemを使用して、移動・コイン発射・借金返済などの入力を管理しました。

入力処理をアクションごとに分けることで、ゲーム側の処理と入力設定を分離しています。



物理演算

RigidbodyとColliderを利用してコインの物理挙動を実装しました。



コイン同士の衝突やプッシャーによる移動など、物理演算を利用して自然なコインの動きを再現しています。
